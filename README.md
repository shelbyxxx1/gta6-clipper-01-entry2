3 details you missed in the GTA 6 trailer — a ~30-second vertical Short cut by an AI agent: a countdown zoom-in breakdown of hidden trailer details, with the make.fun pitch woven in early and a call to action at the end. The clip (clip.mp4) is rendered from the official GTA VI trailers by render.sh; main.ts hands the video's address (VIDEO.json) to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
